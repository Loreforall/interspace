# Stage 12 — release boundary

The core solver is frozen for portfolio purposes. This release adds a mathematics/physics dossier, claim matrix, reproducible numerical console, and agency case study. It does **not** claim that a field barrier is physically feasible or that a manufacturable dome has been demonstrated. Previous stages are research prototypes with known numerical and constitutive limitations.

See `docs/PHYSICS_AND_DERIVATIONS.md`, `docs/MODEL_CLAIM_MATRIX.md`, `docs/REPRODUCIBILITY.md`, `docs/AGENCY_PORTFOLIO_CASE_STUDY.md`.
